# 0.8.1 — Portable macOS Build

Makes the macOS app installable on Macs other than the one that built it, and adds a
distributable disk image. No behavior changes for an existing install.

## Portability

- **Runtime state-directory resolution.** The supervisor previously read an absolute path
  baked into `Info.plist` at build time, which `packaging/build-macos-app.sh` hardcoded to
  the author's home directory. On any other Mac that path did not exist, so `.env` reads
  failed and the server never started. The supervisor now resolves
  `~/Library/Application Support/HoshiStream` at launch. The `HoshiStreamProjectRoot`
  Info.plist key remains as an opt-in development override, set via
  `HOSHISTREAM_PROJECT_ROOT` when building.
- **State directory created before launch.** `Process.run()` fails outright when its working
  directory is missing, which was the normal state on a first launch.

## First-run bootstrap

- **New `scripts/bootstrap.mjs`.** Creates the state directory and writes a `.env` (mode
  `0600`) with a 256-bit `base64url` access token and a `MEDIA_DIR` default. An existing
  `.env` is preserved; only a missing, too-short, or `replace-with…` placeholder token is
  replaced, in place, leaving other settings untouched. The module carries the per-platform
  state and media directory defaults, including the `%LOCALAPPDATA%` variant for the
  eventual Windows port.
- **Library migration tolerates a fresh machine.** `migrateLibrary` read
  `data/library.json` unconditionally and threw when it was absent; it now starts from an
  empty library.
- **`MEDIA_DIR` is created if missing**, alongside the existing upload and TorrServer
  directories.
- **Supervisor tolerates a not-yet-written `.env`,** reporting "Starting…" instead of
  "Error — missing access token" during the first launch.

## Packaging

- **New `packaging/build-macos-dmg.sh`.** Produces `build/HoshiStream-<version>.dmg`
  containing the app, an `/Applications` symlink, and install notes. A disk image preserves
  symlinks, permissions, and the executable bit on the vendored binaries; zip archives
  round-tripped through Finder or chat apps lose them and the app then reports as
  "damaged".
- **Inside-out code signing.** `codesign --deep` is deprecated and a common source of
  "damaged" bundles. Each vendored executable is now signed before the bundle.
- **Bundle version aligned** with the addon package version (`0.2.0` → `0.8.0`), which the
  DMG filename derives from.
- `scripts/bootstrap.mjs` is copied into the app bundle by the build script.

## Known gaps

Distribution still relies on an ad-hoc signature, so recipients must run
`xattr -dr com.apple.quarantine /Applications/HoshiStream.app` once. Developer ID signing
and notarization remain unimplemented. The artifact is Apple Silicon only. See
[guides/distributing-macos-app.md](../guides/distributing-macos-app.md).

## Verification

`npm run typecheck`, `npm test` (201 passing, 13 new bootstrap tests), `npm run lint`, and
`npm run format:check` from `addon/`. The packaged app was additionally started against an
empty state directory to confirm it generates its own configuration and reaches
`native_ready`, and the disk image was mounted to confirm the signature, the
`/Applications` symlink, and executable permissions survive packaging.
