# 0.8.0 — Cinema UI, stream repair, discovery, and in-browser playback

Date: 2026-08-23

## Management UI rebuilt on Preact (no build step)

- Vendored `htm/preact` standalone ESM bundle (13 KB, pinned in
  `assets/manage/vendor/VERSIONS`) — no bundler, no new npm dependency.
- Hash routing (`#/library`, `#/add`, `#/sessions`, `#/status`, `#/play`);
  shared state in `store.js` with a `useStore()` hook; `api.js` is the single
  HTTP layer.
- All views are components now, including the 490-line detail modal, which is
  rendered from state instead of imperative DOM calls.
- New dev loop: `npm run dev:tsc` + `npm run dev`
  (`node --watch --env-file=.env`); UI edits need only a browser refresh.

## Cinema redesign

- Navigation moved out of the HTML shell into a preact glass top bar with a
  pill nav and global search.
- The library gained a hero section spotlighting the most recently played
  title (resume / watch in browser / details), driven by playback state.
- Poster cards show the direct-play verdict as a colored dot with hover
  actions; `styles.css` was rewritten around dark glass surfaces and a warm
  orange accent, restyling every view through the shared classes.

## Opt-in real-time stream repair (ADR 0010)

Off by default (`TRANSCODE_ENABLED=false`). When enabled, entries whose probe
verdict predicts a TV playback failure get extra streams in the Stremio picker:

- **Compatible** — tier chosen from the verdict: copy-only remux for MKV/AVI
  containers, AC3 audio conversion for DTS/TrueHD-class tracks, or a
  `h264_videotoolbox` hardware re-encode for undecodable video (AV1, VP9, VC-1,
  MPEG-2). No hardware encoder → no video tier; software encoding is never
  used.
- **Lower bitrate** — offered to remote (tunnel) clients when the original
  bitrate exceeds `TRANSCODE_VIDEO_BITRATE_MBPS` (default 8).

Sessions start lazily on the first playlist request, serve fMP4 HLS from
`<state dir>/transcode/`, are reaped 60 s after segment requests stop, swept at
startup, and capped by `TRANSCODE_MAX_SESSIONS` (default 2). ffmpeg is a new
vendored, pinned, checksum-verified runtime (`packaging/ffmpeg-lock.json`).

## Management surface

- New "Stream Repair" view: live session table with per-session Stop.
- Library cards show the direct-play verdict badge; the detail Playback tab
  gains an "Always offer the Compatible stream" toggle (`forceTranscode`).
- `/api/status` reports repair state and hardware-encoder availability.

## In-browser player

- New `#/play/{entryId}/{fileId}` view plays the same stream URLs the TV
  clients receive; Direct / Compatible / Lower-bitrate renditions are
  switchable in place. HLS plays natively on Safari and through vendored
  hls.js 1.7.1 elsewhere; resume positions live in `localStorage`.
- Series get an episode rail (season chips + episode buttons), previous/next
  controls, and an autoplay-next toggle; "Watch in browser" starts at the
  last-played episode.
- "Watch in browser" buttons in the detail modal and library hero, plus a
  per-file browser-play button in the detail Files tab.
- The management CSP gained `media-src` and `worker-src` allowances for
  TorrServer-origin direct play and MediaSource playback.

## LAN discovery (ADR 0011)

- The add-on advertises `_hoshistream._tcp` over mDNS via a dependency-free
  responder (`mdns.ts`): announce on start, goodbye on shutdown, re-announce
  on LAN IP change. The TXT record never carries the token. Config-gated with
  `MDNS_ENABLED` (default on). An external rendezvous service was evaluated
  and rejected on privacy grounds.

## Measured connection speed

- The static `HOME_SPEED_MBPS` figure is now only a fallback: the add-on
  measures real download speed against Cloudflare's open speed-test endpoint
  (`speed.cloudflare.com/__down`, plain fetch, no dependencies) once at
  startup and on demand — `POST /api/speedtest`, a "Run speed test" button on
  the Status page, and "Check Speed" in the menu bar. The measured value
  drives all direct-play guidance and the status displays.

## Fixes

- Season packs no longer surface featurette/deleted-scene files as episodes
  (a 2 MB "S02E05" deleted scene had shadowed the real 720 MB episode).
- Torrent probes get 180 s instead of 45 s — cold swarms need over a minute
  to serve header pieces, which made every first "Analyze playback" fail.
- `probeMedia` honors `FFPROBE_PATH`; the supervisor points it at the
  vendored ffprobe.
- `start-native.sh` launches the supervisor with `--detached`, so the parent
  watchdog (built for the macOS app's crash path) no longer kills a
  terminal-launched stack two seconds after startup.
- The placeholder access token was rotated to a generated 48-character value.

## Known gaps

- On-TV webOS validation of the HLS output is pending.
- While a repair session is still encoding, the player shows no total
  duration (`--:--:--`) — the growing EVENT playlist looks like a live
  stream. Total time and full seeking appear automatically once the whole
  file has been remuxed, which is bounded by torrent download speed.
- Far seeks into a still-encoding tier-V session wait for the encoder; `-ss`
  restart sessions were deferred (see the transcoding plan).
- Windows hardware encoding (`h264_mf`) is recognized but untested.
