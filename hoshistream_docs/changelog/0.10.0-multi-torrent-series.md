# 0.10.0 — Multi-torrent series

One series entry can now be backed by several torrents
([plan](../plans/2026-09-01-multi-torrent-series-plan.md)).

## Add-on

- New optional `extraSources` on series entries: extra magnets/.torrent
  files, each with an optional `seasonHint` and its own `fileOverrides`.
  Torrent-backed series only; rejected on movies and local entries.
- Composite file IDs (`sourceIndex × 100000 + fileId`) keep files unique per
  entry while the primary source keeps raw IDs, so existing caches, playback
  positions, and HLS URLs stay valid.
- `selectMediaFiles` gained a `seasonHint` fallback (filename numbering
  wins); `mergeSelectedFiles` combines sources, later source winning on
  duplicate episodes.
- Inspection registers every source; cached stream resolution re-registers
  only the specific missing torrents. `TorrServerClient.streamUrl` decodes
  composite IDs and prefers the file's own hash.
- Editing `extraSources` invalidates the inspection cache.

## Management UI

- Add Media (magnet source): "+ Add another torrent" rows with optional
  season number.
- Detail → Source: list, add, and remove extra torrents on existing series.

## Limitations

- Per-file overrides for extra sources are API-only for now (the UI edits
  the primary source's overrides).
- Extra `.torrent` files uploaded through the API are not tracked as managed
  media.
