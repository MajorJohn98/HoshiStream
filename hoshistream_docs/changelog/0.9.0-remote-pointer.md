# 0.9.0 — Remote pointer: a permanent add-on URL

Fixes the "re-enter the manifest URL after every IP change" problem
([plan](../plans/2026-09-01-stable-manifest-pointer-plan.md),
[ADR 0012](../decisions/0012-vercel-pointer-server.md)).

## Pointer server (`pointer/`)

- New self-deployed Vercel project: serves the stored manifest at
  `/addon/<token>/manifest.json` and `307`-redirects all other add-on
  requests to the Mac's last-pushed LAN base URL.
- Stores a single Blob record — LAN base URL, SHA-256 token hash, manifest
  copy, timestamp — at a pathname derived from the push secret. No library
  data, no media, no token.
- `POST /api/pointer` guarded by a `PUSH_SECRET` bearer token; payloads
  validated with Zod; wrong add-on tokens answered 401 via constant-time
  hash comparison.

## Add-on

- New optional config: `POINTER_URL`, `POINTER_PUSH_SECRET` (feature is off
  unless both are set), `POINTER_STATE_PATH` for the persisted last push.
- `PointerClient` (`src/pointer.ts`): manual push of
  `{ baseUrl, token, manifest }`, persisted last-push state, staleness
  detection against the current LAN IPv4.
- Management API: `POST /api/pointer/push`, `GET /api/pointer/status`;
  `/api/status` now reports `pointer.configured` / `pointer.stale`.
- The native launcher forwards the pointer variables and pins the state file
  to the state directory.

## macOS menu bar

- New "Update Remote Pointer" item (hidden unless configured) with
  `⚠︎ IP changed` staleness warning and push feedback.
- "Copy Stremio URL" copies the permanent pointer URL when configured,
  falling back to the LAN URL otherwise.

## Behavior notes

- Nothing is sent automatically — the pointer updates only on click.
- A missed update after an IP change fails playback until one click on the
  Mac; clients never need reconfiguring.
- Vercel outage does not affect the LAN URL path.
