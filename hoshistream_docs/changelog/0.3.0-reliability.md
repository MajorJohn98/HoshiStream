# 0.3.0 — Reliability

Focused reliability work covering both the Docker stack and the native macOS
app. See `plans/2026-08-12-reliability-plan.md` for the assessment behind it.

## Changes

- **Version control.** The project is now a git repository; `.gitignore`
  excludes secrets, build artifacts, runtimes, and mutable state (including
  `data/library.json`, which can contain magnet URIs).
- **Host-derived public URLs** (ADR 0005). Stream responses rewrite the
  add-on and TorrServer origins from the request `Host` header with a fallback
  to the configured URLs, so a LAN IP change no longer breaks playback.
- **Library backup and recovery.** Every successful write refreshes
  `library.json.bak`; an unreadable library is quarantined as
  `library.json.corrupt-<timestamp>` and the backup is restored
  automatically. A missing library now starts empty instead of erroring.
- **TorrServer retries.** Network errors and 5xx responses are retried up to
  twice with exponential backoff; 4xx responses and the multipart upload are
  never retried.
- **Inspection cache** (ADR 0006). Successful inspections persist
  `{hash, selectedFiles, inspectedAt}` on the entry; streams and series
  metadata resolve from the cache instantly instead of re-polling metadata for
  up to 30 s.
- **Native supervisor restarts.** Up to five crash restarts with exponential
  backoff (2 s–30 s) instead of giving up after one; `ADDON_PORT` from `.env`
  is now honored consistently by the server, health check, and copied
  Stremio URL.
- **Sleep prevention during playback.** `/api/status` reports
  `streamingActive` (recent stream activity or active TorrServer torrents);
  the menu-bar app holds a `PreventUserIdleSystemSleep` assertion while it is
  true, replacing the manual `caffeinate` workaround. Lid-closed sleep is
  unchanged.

## Validation

`npm run typecheck`, `npm test` (42 passed, 1 opt-in skipped), `npm run lint`,
`npm run format:check`, `docker-compose config -q`, Swift `-typecheck`, and a
full `packaging/build-macos-app.sh` rebuild.
