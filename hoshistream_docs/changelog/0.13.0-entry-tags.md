# 0.13.0 — Entry tags with a dynamic registry

Genre-style tags for library entries, a Library tag filter, and a **Tags** page
to grow the vocabulary ([plan](../plans/2026-09-04-entry-tags-plan.md)).

## Tags

- New `tags?: string[]` on library entries (≤ 32, ≤ 40 chars each, unique
  case-insensitively). Stored by name so `library.json` stays readable.
- Registry `tags.json` (`TAGS_PATH`, state dir) via `src/tags.ts`. Seeded on
  first run with the union of the TMDB and IMDb genre lists — Action,
  Adventure, Animation, Anime, Biography, Comedy, Crime, Documentary, Drama,
  Family, Fantasy, Film-Noir, Game Show, History, Horror, Kids, Music, Musical,
  Mystery, News, Reality, Romance, Sci-Fi, Soap, Sport, Talk Show, Thriller,
  War, Western.
- `Library.retag(from, to?)` cascades renames and deletions through entries.
- `/api/tags` (`GET` with usage counts, `POST`, `PATCH /{name}`,
  `DELETE /{name}`). `POST/PATCH /api/library` normalize `tags` to the
  registry's spelling and register unknown names; `tags: null` clears.

## Stremio

- Catalogs advertise a `genre` extra whose `options` are the live tag list
  (`manifestWithGenres`, applied when the manifest is served and when it is
  pushed to the pointer server). `getCatalog` filters on `genre`; catalog and
  meta previews include `genres`.

## Management UI

- **Library**: tag chips under the type filters (only tags in use), AND
  semantics, "✕ Clear"; cards show up to two tags; `#/library/tag/<name>`
  deep-links a filter.
- **Entry sheet** Overview form and **Add Media** modal: `TagPicker` — toggle
  chips plus an inline "New tag…" input.
- **Tags** page (`#/tags`, sidebar `⌗`): registry list with usage counts,
  add, inline rename, delete (confirm when in use). Tag names link to the
  filtered Library.

## Tests

- `tests/tags.test.ts`: registry seeding/permissions, case-insensitive
  add/rename/remove, `ensure()`, `Library.retag`, `manifestWithGenres`, and the
  `/api/tags` flow through the real dispatcher.
- `tests/catalog.test.ts`: `genre` filtering and `genres` output.

## Fixes

- Entry sheet Overview form: the Title, Poster URL, Background URL, and
  episode-mapping inputs no longer revert while typing. They were bound with
  `value`, which preact re-syncs to the DOM on every render — and the sheet
  re-renders on each activity poll. They now use `defaultValue`.

## UI consistency pass

A polish pass over the management UI (impeccable `polish`), preserving the
Cinema-shelf look and fixing drift rather than redesigning:

- **Tokens** for the type scale (`--fs-display` 30px for heroes, `--fs-title`
  26px for pages, heading/body/control/small/micro), control metrics, and a
  spacing rhythm (`--space-2…5`). The entry sheet's title now matches the
  Library hero instead of a one-off 27px.
- **One control height.** Buttons, text inputs, selects, and the tag picker
  all render at 38px in a row; native `time` inputs are pinned to match.
  `<select>` is now styled (WebKit ignored its padding, leaving 20px-tall
  bare selects beside 41px inputs) with a drawn chevron.
- **Focus, selection, scrollbar** themed from the palette (`:focus-visible`
  ring, `::selection`, `scrollbar-color`); primary buttons keep the ring
  alongside their shadow; poster cards show a ring on keyboard focus.
- **Headings.** Duplicate panel titles under the sheet's section labels
  ("Keep on disk / Keep on disk", "Source / Source") removed; form group
  labels ("Tags", "Additional torrents") use the same muted 12.5px label
  style as every other field instead of bold body text.
- **Inline styles removed** from all views (31 one-offs → `stacked`,
  `stacked-sm/xs`, `row tight/between`, `grow`, `check`, `input-narrow`,
  `repeater-row`, `modal.narrow`, `progress`). The player keeps its one
  dynamic style.
- **Controls.** The unstyled "Update remote pointer" button becomes the
  panel's primary action with a `danger` Remove beside it; clickable metric
  tiles (clients, entries kept on disk) are `role="button"`, focusable, and
  keyboard-activatable with a hover state.
- **Motion.** Progress bars animate `transform: scaleX()` instead of
  `width` (detector: layout-transition).
- **Mobile.** Sheet, modal, and form paddings tighten below 900px; tag rows
  wrap to name / count + actions; the Tags header form stays on one line.
- Dead CSS (`.head-actions`, `.episode-rail`) removed.
- Overlay close buttons (entry sheet, Add Media, import review, Stremio
  refresh): the text "×" (an 18px-tall glyph in a 34px circle with default
  button padding) is now a drawn 14px SVG cross centred with `place-items`;
  the button gains hover/active states it never had, a stronger border and
  blur so it stays legible over poster art, and sits on each surface's own
  content margin (30px on the sheet, 26px in modals) instead of 14px from
  the corner.
