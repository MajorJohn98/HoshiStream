# 0.1.0 — MVP

All five MVP implementation phases are complete.

## Phase summaries

1. **Stack foundation** — Apple Silicon Docker Compose stack (pinned TorrServer MatriX.141.1 + Node 22 add-on image), memory/CPU limits, healthchecks, log rotation.
2. **Library and management** — Tokenized manifest, atomic JSON library, catalogs with search and pagination, metadata resource, bearer-authenticated management API.
3. **TorrServer integration** — Magnet and `.torrent` registration (`save_to_db: false`), metadata polling with a 30 s deadline, inspection, removal, and playable media-file selection.
4. **Streaming** — Movie streams, series episode mapping from filename patterns (`S01E02`, `1x02`), and public TorrServer URL rewriting for direct play.
5. **Operations** — Bounded 2 GiB disk cache, 5-minute inactive cleanup, structured JSON logs (no tokens/magnets), unit + optional integration tests, documentation.

## Post-MVP additions (0.2.0 manifest)

- Native macOS menu-bar app: bundled Node + TorrServer runtimes, Swift supervisor, Finder file/folder pickers over a Unix socket, relink support, managed browser uploads.
- Local media streaming with HTTP range support (`/local/...`).
- Technical media probe (resolution, codecs, bitrate) with a home-speed viability verdict.
- Embedded management web page at `/manage/{token}`.

## Known gaps

- Live Mac/webOS playback validation with authorized media is still outstanding.
- The project folder is not yet under git version control.
