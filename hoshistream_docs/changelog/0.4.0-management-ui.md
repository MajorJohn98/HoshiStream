# 0.4.0 — Management UI overhaul

## Restructure

- The management UI moved out of the ~30 KB inline template string in `management.ts` into plain ES modules under `addon/assets/manage/` (`app.js` entry, `classify-imports.js`, `styles.css`, and one module per view). `management.ts` is now a thin HTML shell.
- New public `GET /manage-assets/{file}` route serves the assets with a whitelisted-name guard (no path traversal), correct content types, and a 5-minute cache.
- The page CSP dropped both `unsafe-inline` directives: `script-src 'self'; style-src 'self'`.
- No packaging changes were needed — Docker and the macOS app already ship `addon/assets/` wholesale.

## Functional improvements

- `GET /api/status` now reports `nativePicker`, true when the supervisor socket exists and Finder pickers can work.
- **Finder linking in Add Media** — when the native app is running, the Local file and Series folder cards offer "Choose with Finder", which links media in place via a `nativePathGrant` instead of copying it into managed storage. Browser upload remains as the fallback and the only path in Docker mode.
- **Relink in Finder** — the detail Source tab exposes `POST /api/library/{id}/relink` for local entries, previously unreachable from the UI.
- **Cache-aware detail view** — the Files tab renders the entry's `inspectionCache` (selected files, sizes, episode mapping, cache age) instantly; a full inspection is only needed to edit the mapping. The Source tab shows when the entry was last inspected.
- **System Status refresh** — Streaming now/Idle pill from `streamingActive`, native app vs Docker mode indicator, an accurate Mac-sleep note (automatic in native mode, caffeinate hint otherwise), and the fake Settings nav button was removed.

## Compatibility

- All API shapes and the library import/export JSON format are unchanged; `/api/status` only gained a field.
- `classifyLibraryImports` moved from `addon/src/management.ts` to `addon/assets/manage/classify-imports.js` (single source of truth, imported directly by tests).
