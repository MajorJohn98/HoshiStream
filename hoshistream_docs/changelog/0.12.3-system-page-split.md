# 0.12.3 — System page split into Status, Activity, and Storage; Add Media becomes a modal

The single scrollable **System** page from 0.12.0 grew too long to scan. Its
five sections are now three pages plus a Library toolbar action, grouped by the
question the user is asking rather than by source file.

## Pages

| Page         | Route        | Contents                                                             | Answers                             |
| ------------ | ------------ | -------------------------------------------------------------------- | ----------------------------------- |
| **Status**   | `#/status`   | Health: services, library stats, connection speed, resources, checks | "Is the server OK?"                 |
| **Activity** | `#/activity` | Devices (clients, live playback, remote pointer) + Stream repair     | "Who's watching, what's happening?" |
| **Storage**  | `#/storage`  | Volumes, download schedule, archive queue, entries kept on disk      | "Where does my media live?"         |
| _Library_    | `#/library`  | **Playback analysis** moved here behind a "◌ Analyze" toolbar button | —                                   |

Devices and Stream repair sit together because both are live sessions fed by
the same activity poller. Analysis acts on library entries, so it belongs with
Import / Export / Refresh Stremio; the button shows the unanalyzed count
("◌ Analyze · 3") and `#/library/analysis` opens the panel directly.

**Add Media** is no longer a page: the **+ Add Media** button in the Library
toolbar opens it as a modal over the current view (Escape, backdrop click, or
Cancel close it; a successful add closes it and refreshes the grid). The
sidebar has four destinations: Library, Status, Activity, Storage. HUD rows
link to Status (health), Activity (streaming, repairing), and Storage (copies,
drive warnings).

## Compatibility

Every old route redirects: `#/system` and `#/system/health` → `#/status`;
`#/system/devices` → `#/activity`; `#/system/repair` (and pre-0.12
`#/sessions`) → `#/activity/repair`; `#/system/storage` → `#/storage`;
`#/system/analysis` → `#/library/analysis`; pre-0.12 `#/devices` →
`#/activity`; `#/add` → `#/library` with the Add Media modal open.

## Files

- New `assets/manage/views/activity.js` (`ActivityView`) and
  `views/analysis.js` (`AnalysisPanel`, `unanalyzedCount`).

  `views/storage.js`; `views/system.js` removed.

  `.modal-backdrop.add-backdrop`), with `openAdd()` / `closeAdd()` toggling

  `LEGACY_ROUTES`, `#/add` handled as a modal opener, HUD links repointed.
- `.system-section` CSS renamed `.page-section`; `.analysis-panel` and
  `.add-modal` added.
- No server-side changes.
