# 0.12.1 — Router split and hot-path trims

A maintenance release with no user-visible behavior change. It follows a review of
the 0.12.0 codebase that found one structural problem and a handful of small
inefficiencies on the playback path.

## The router is now a set of modules

`routes.ts` had grown to 1,236 lines: one `if` chain covering every endpoint, fed by
an eighteen-parameter `createHandler` whose trailing optional arguments had to be
passed positionally. Adding a route meant finding the right spot in the chain and
threading another dependency through the signature.

The handler is now a small dispatcher over two ordered lists of `RouteHandler`
functions — open routes (health, assets, the tokenized Stremio protocol, playback
URLs) and `/api/*` routes, which share one bearer-token check. Each handler receives a
`HandlerContext` and a `RouteRequest`, and returns `true` once it has written a
response. Routes live in `addon/src/routes/` grouped by concern: `protocol`, `media`,
`library-api`, `disk-api`, `system-api`. `createHandler` takes a single
`HandlerOptions` object; `index.ts` was updated to match.

Error mapping moved to `routes/errors.ts`. The old handler classified the error twice
(once for the status, once for the message) with two `instanceof` chains; a single
`classifyError` now returns both.

The public helpers tests import — `technicalProbeRequested`,
`noStoreProtocolResource`, `manageAssetPath` — are re-exported from `routes.ts`, so
existing tests are untouched. A new `tests/routes.dispatch.test.ts` spins up the real
handler against a temp library and a stubbed TorrServer client to pin the dispatch
behavior: token gating, protocol proxying, library CRUD, 400/404/409 mapping, and
static asset serving.

## Less work per range request

Every `/local` and `/media` range request — which arrive continuously during
playback — did two full-library round trips:

- `Library.get(id)` called `list()`, which `structuredClone`d every entry before
  picking one. It now clones only the matched entry.
- `Library.markStreamed(id)` re-read the library just to check its three-minute
  throttle. The last-write time is now kept in memory per entry; the disk read only
  happens when a write is actually due, and a second check against the stored
  timestamp keeps concurrent processes honest.

`Library.update` clones before mutating so the shared cache stays pristine; `list()`
still returns a full clone, and a regression test guards against callers mutating
cached entries through either `list()` or `get()`.

## TorrServer client releases failed responses

`TorrServerClient.request` threw or retried on non-2xx responses without consuming
the body. With undici that keeps the connection pinned until the `Response` is garbage
collected, which can starve the pool during a retry storm against a struggling
TorrServer. The body is now cancelled before the error path runs.

## Hostname cache is LRU

`hostname.ts` evicted the oldest-inserted entry when its 256-entry cache filled. Hits
now re-insert the key so `Map` iteration order tracks recency and the eviction is
least-recently-used.
