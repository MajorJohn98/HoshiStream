# 0.14.0 — Instrument-panel UI: rows instead of cards, dots instead of badges

The operate pages (Status, Activity, Storage, Tags) and the entry sheet were
card-heavy: panels holding grids of "metric" boxes, and status expressed as
pills and badges everywhere. This release replaces that with a flat,
hairline-separated data language while keeping the Cinema-shelf world (dark
surfaces, ember accent, poster-forward Library).

## Design language

- **Sections, not cards.** Each page is a stack of sections with a small-caps
  title, an optional one-line note, and a right-aligned summary or action in
  the section head. No panel wraps read-only data; panels survive only for
  forms and tables.
- **Rows** (`.rows` / `.rowitem`): status dot · title + meta · trailing value
  or action, separated by hairlines. Used for services, checks, clients,
  streaming sessions, repair sessions, volumes, kept-on-disk titles, and the
  archive queue (with an inline 3px progress bar).
- **Stat strips** (`.stats` / `.stat`): label over a 20px tabular value with
  hairline dividers, for the Status overview and resources.
- **Key/value lists** (`dl.kv`) for technical detail: source kind/location and
  the playback analysis table.
- **Status is a dot and a word** (`.status`), never a pill. Pills are gone;
  the only remaining badge marks import conflicts. Hero and sheet metadata is
  a single dotted text line (type · source · tags · verdict).
- **Segmented control** replaces the four source cards in Add Media, with a
  one-line hint per source.

## Pages

- **Status**: Services (HoshiStream / TorrServer / Stream repair rows with a
  live "Streaming now" indicator), Overview stats (library, speed, uptime,
  with Run speed test in the head), Resources (process stats + cache sizes),
  Checks (pass count in the head).
- **Activity**: Now streaming → Connected clients (rows are focusable and
  rename on click) → Remote pointer (actions in the section head; pointer and
  server as two rows) → Stream repair (Stop action inline).
- **Storage**: Volumes (add action in the head) → Kept on disk → Archive queue
  → Download window (state as a status line, no pill).
- **Tags**: plain rows, counts as tabular text.
- **Entry sheet**: Source and Playback check flattened to key/value lists with
  a verdict status line; Keep on disk status line replaces three badges;
  duplicate panel wrappers removed.

## Removed

`.metrics/.metric`, `.pill/.statusbar`, `.source-card(s)`, `.layout`,
`.route`, `.hero-meta`, `.head-actions` CSS and the `Pill` component.

## Entry sheet (follow-up)

The title sheet now speaks the same language as the pages:

- Every section has a **section head** — small-caps title, one-line note,
  status on the left, the section's primary action on the right ("Inspect
  again", "Inspect to edit" / "Save mapping", "Refresh analysis", "Analyze
  playback"). No boxed forms, dashed empty boxes, or duplicated headings.
- The sticky chip nav is a **tab strip** (text with an underline on hover).
  Section order is Details → Source → Files → Playback check → Keep on disk.
- Empty states are quiet one-liners with the action in the head ("Not
  inspected yet — load the source's metadata to choose files").
- Keep on disk: file lists are rows with a state dot (or a checkbox when
  choosing episodes) instead of ✓◔○⚠ glyphs; the volume moves into the note
  and the completion state into the head.
- Additional torrents are rows; the file tables sit flat on the sheet.
- **TagPicker** is redesigned: instead of 29 toggle chips, the entry's tags
  are removable chips inside one input that suggests registered tags
  (`datalist`) and creates new ones on Enter; Backspace removes the last.
  Details shrinks by ~160px and reads as a form field like the others.

## Server

- Management assets revalidate with an ETag (`cache-control: no-cache`, 304
  on match) instead of `max-age=300`. After an upgrade a stale module mixed
  with fresh ones broke the page for up to five minutes; during development
  edits now show on plain refresh.

## Entry sheet tabs and season lists

- The sheet's sections are now **real tabs** (`role="tablist"`, arrow-key
  navigation): only the active section renders, so the sheet is roughly the
  hero plus one section tall instead of five stacked sections. `state.tab`
  still selects the tab, so Storage deep links open Keep on disk directly.
- File lists show **about ten rows and scroll** (`.scroll-table` /
  `.scroll-list`, sticky header). When a title spans several seasons, a
  **season sub-tab strip** with per-season counts filters the list — in the
  cached files table, the mapping editor (hidden rows stay in the DOM so Save
  mapping still writes every file), and Keep on disk's episode picker, where
  the per-season toggle applies to the selected season.
- File names show the base name (full path on hover) and sizes no longer wrap.
